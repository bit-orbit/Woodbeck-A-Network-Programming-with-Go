## ۱. درباره این کتاب
راهنمای جامع توسعه سوکت‌های شبکه، استریم‌های TCP، ارتباطات نامطمئن و پرسرعت UDP، سوکت‌های یونیکس، کلاینت‌ها و سرورهای امن HTTP و رمزنگاری TLS با زبان Go.
